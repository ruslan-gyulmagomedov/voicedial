# История изменений

## 1.2 — 12.11.2026

- Перед прослушиванием больше нет голосовой подсказки: вместо «Говорите имя»
  и «Кому позвонить?» звучит короткий сигнал. Всё остальное по-прежнему
  озвучивается.
- Звонки в Telegram идут через установленный клиент, а не только через
  официальный: Nicegram и другие форки распознаются, клиент выбирается по
  приложению по умолчанию для ссылок `tg://`, иначе — установленный
  сторонний клиент.
- Строка записной книжки «позвонить» ищется по любому клиенту, а не только
  по официальному MIME; выбранному клиенту действие отдаётся напрямую.
- В озвучке называется клиент, через который идёт звонок: «Звоню Роме
  в Nicegram».

## 1.1 — 12.11.2026

- Звонки в Telegram: «позвони Роме в Telegram», «позвони Маше в телеге»,
  «позвони в тг Роме». Название мессенджера вырезается из фразы, контакт
  ищется по имени среди записной книжки.
- Звонок запускается действием «позвонить», которое Telegram кладёт в
  записную книжку; запасной путь — `tg://call?phone=`.
- Звонок по номеру в Telegram: «позвони 89261234567 в телеграм».
- Если Telegram не установлен, приложение говорит об этом голосом.
- Для поиска Telegram в системе добавлены запросы в манифесте
  (`<queries>`) — требование Android 11+.

## 1.0

- Первый выпуск: голосовой набор контакта по имени, выбор из нескольких
  совпадений, звонок по номеру, озвучивание через TTS.
