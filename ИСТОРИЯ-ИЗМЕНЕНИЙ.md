# История изменений

## 1.10 — 14.11.2026

- Возврат к поведению 1.8: поддержка MAX убрана. «Позвони Роме в макс»
  снова не распознаётся как мессенджер, звонки идут туда же, куда в 1.8, —
  обычная связь, Telegram, WhatsApp и ВКонтакте.
- Номер версии выше 1.9, поэтому обновление ставится поверх неё как
  обычное: удалять приложение не нужно, настройки и запомненный клиент
  сохраняются. Пересобранная 1.8 с прежним номером поверх 1.9 не
  установилась бы — Android не откатывает версии назад.

## 1.9 — 14.11.2026 (отозвана)

- Выпуск с поддержкой MAX отозван: MAX не даёт другим приложениям
  начинать звонок, поэтому пользы от него не было. Код возвращён к 1.8.
- Подробности выпуска: «позвони Роме в макс» открывал MAX и просил нажать
  трубку в чате; по номеру звонить отказывался; «позвони Максу» оставалось
  именем.

## 1.8 — 13.11.2026

- Звонки через WhatsApp: «позвони Роме в ватсап», «в вотсапе», «в вацап»,
  «в WhatsApp», «через ватсап». Понимается и разбитое распознаванием
  «в вот сап». Работают обе версии — обычный WhatsApp и WhatsApp Business.
- Звонки во ВКонтакте: «позвони Роме в вк», «во вконтакте», «в контакте».
- Название мессенджера вырезается из фразы, где бы оно ни стояло, поэтому
  имя ищется так же надёжно, как без него.
- По номеру в WhatsApp и ВК позвонить нельзя — там нет такой возможности.
  Приложение честно говорит об этом и просит назвать имя контакта, а не
  звонит молча обычной связью.
- Долгое нажатие на «Слушаю» сбрасывает выбор клиента у всех мессенджеров.
- Если в новой фразе мессенджер не назван, это обычный звонок: неудачная
  попытка позвонить в Telegram больше не тянется в следующую фразу.

## 1.7 — 13.11.2026

- Имя ищется по словам, а не по всей строке целиком. Склонения
  разбираются у каждого слова отдельно: «позвони Никите», «позвони
  Никитой», «позвони Ивановой», «позвони Сергеевичу» находят контакт
  независимо от падежа.
- Фамилия понимается: «позвони Гюльмагомедову» находит «Руслан
  Гюльмагомедов». Имя и фамилию можно говорить в любом порядке и в любом
  падеже — «Руслану Гюльмагомедову», «Гюльмагомедову Руслану».
- Уменьшительные имена: «Саше» находит «Александр», «Маше» — «Мария»,
  «Пете» — «Пётр», «Роме» — «Роман».
- Служебные слова не мешают: «позвони мне, пожалуйста, Маше», «позвони
  Маше в телеграм» — лишнее отбрасывается до сравнения.
- Похожие контакты больше не путаются: «Оле» не находит «Олег», «Маше» —
  «Миша», «Ане» — «Антон», «Ивану» — «Иванова». Совпадение по одному
  слову из двух слабее полного, поэтому никто не перебивает точное имя.

## 1.6 — 13.11.2026

- Клиент Telegram определяется как приложение, которое система открывает по
  ссылкам `tg://`, — то, что выбрано в настройках телефона «по умолчанию для
  ссылок». Раньше проверялся только флаг `isDefault`, который прошивки
  выставляют не всегда, и приложение спрашивало клиента, даже когда выбор
  уже сделан.
- Если приложение для ссылок назначено, приложение больше не спрашивает —
  звонит через него, даже если это официальный Telegram, а рядом стоит форк.
- Спрашивает голосом только когда приложение для ссылок не назначено и
  клиентов несколько. В подсказке теперь сказано, что выбор можно сделать в
  настройках телефона и тогда вопроса не будет.
- Запомненный голосом выбор стал запасным вариантом: назначенное в системе
  приложение важнее.

## 1.5 — 12.11.2026

- Свой постоянный идентификатор приложения: `ru.gyulmagomedov.voicedial`.
  Ставится отдельно от оригинала и обновляется поверх предыдущих версий —
  с этого выпуска новые сборки устанавливаются как обновление, без удаления.
- Сборки подписываются постоянным ключом (`keystore/voicedial.jks`) и для
  debug, и для release. Раньше ключ генерировался заново на каждом
  сборщике, и Android отказывался ставить новую версию поверх старой.
- Клиент Telegram выбирается по обработчику ссылок `tg://` по умолчанию:
  если система назначила клиента, звоним через него.
- Если обработчика по умолчанию нет и установлено несколько клиентов,
  приложение спрашивает голосом: «Установлено несколько клиентов Telegram:
  1. Nikogram, 2. Telegram. Скажите номер клиента». Выбор запоминается.
- Долгое нажатие «Слушаю» сбрасывает запомненный выбор клиента — приложение
  спросит заново.
- Фраза больше не зависит от названия клиента: подходит любое слово с
  «грам»/«gram» в любом падеже («в телеграме», «в некограмме», «в найсграм»,
  «в никаграме»). Единицы веса и «инстаграм» по-прежнему не считаются
  мессенджером.

## 1.4 — 12.11.2026

- Исправлено: фраза с названием клиента («позвони Роме в Никограм») больше
  не уходит в обычный телефонный звонок. Раньше мессенджером считались только
  «телеграм», «телега» и «тг», а «Никограм» не распознавался.
- Мессенджером теперь считается и название любого клиента: «Никограм»,
  «Некограм», «Найсграм», «Nicegram», а также любое слово с окончанием
  «грам»/«gram» — так находится и незнакомый форк, даже если распознавание
  речи слегка исказило название. «Инстаграм» исключён.

## 1.3 — 12.11.2026

- Клиент Telegram больше не задан списком пакетов: приложение спрашивает
  систему, какие приложения открывают ссылки `tg://`, и берёт сторонний
  клиент — Nikogram, Nekogram, Nicegram и любой другой форк находятся сами,
  без знания их внутреннего имени.
- Сторонний клиент в приоритете перед официальным Telegram, даже если
  официальный назначен обработчиком ссылок по умолчанию.
- Строка «позвонить» в записной книжке выбирается по предпочтённому клиенту;
  если такой строки нет — берётся строка стороннего клиента, и только потом
  официального.
- Исправлена формулировка README: пример озвучки без привязки к конкретному
  клиенту.

## 1.2 — 12.11.2026

- Перед прослушиванием больше нет голосовой подсказки: вместо «Говорите имя»
  и «Кому позвонить?» звучит короткий сигнал. Всё остальное по-прежнему
  озвучивается.
- Звонки в Telegram идут через установленный клиент, а не только через
  официальный: Nicegram и другие форки распознаются, клиент выбирается по
  приложению по умолчанию для ссылок `tg://`, иначе — установленный
  сторонний клиент.
- Строка записной книжки «позвонить» ищется по любому клиенту, а не только
  по официальному MIME; выбранному клиенту действие отдаётся напрямую.
- В озвучке называется клиент, через который идёт звонок: «Звоню Роме
  в Nicegram».

## 1.1 — 12.11.2026

- Звонки в Telegram: «позвони Роме в Telegram», «позвони Маше в телеге»,
  «позвони в тг Роме». Название мессенджера вырезается из фразы, контакт
  ищется по имени среди записной книжки.
- Звонок запускается действием «позвонить», которое Telegram кладёт в
  записную книжку; запасной путь — `tg://call?phone=`.
- Звонок по номеру в Telegram: «позвони 89261234567 в телеграм».
- Если Telegram не установлен, приложение говорит об этом голосом.
- Для поиска Telegram в системе добавлены запросы в манифесте
  (`<queries>`) — требование Android 11+.

## 1.0

- Первый выпуск: голосовой набор контакта по имени, выбор из нескольких
