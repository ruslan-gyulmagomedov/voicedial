# История изменений

## 1.5 — 12.11.2026

- Свой постоянный идентификатор приложения: `ru.gyulmagomedov.voicedial`.
  Ставится отдельно от оригинала и обновляется поверх предыдущих версий —
  с этого выпуска новые сборки устанавливаются как обновление, без удаления.
- Сборки подписываются постоянным ключом (`keystore/voicedial.jks`) и для
  debug, и для release. Раньше ключ генерировался заново на каждом
  сборщике, и Android отказывался ставить новую версию поверх старой.
- Клиент Telegram выбирается по обработчику ссылок `tg://` по умолчанию:
  если система назначила клиента, звоним через него.
- Если обработчика по умолчанию нет и установлено несколько клиентов,
  приложение спрашивает голосом: «Установлено несколько клиентов Telegram:
  1. Nikogram, 2. Telegram. Скажите номер клиента». Выбор запоминается.
- Долгое нажатие «Слушаю» сбрасывает запомненный выбор клиента — приложение
  спросит заново.
- Фраза больше не зависит от названия клиента: подходит любое слово с
  «грам»/«gram» в любом падеже («в телеграме», «в некограмме», «в найсграм»,
  «в никаграме»). Единицы веса и «инстаграм» по-прежнему не считаются
  мессенджером.

## 1.4 — 12.11.2026

- Исправлено: фраза с названием клиента («позвони Роме в Никограм») больше
  не уходит в обычный телефонный звонок. Раньше мессенджером считались только
  «телеграм», «телега» и «тг», а «Никограм» не распознавался.
- Мессенджером теперь считается и название любого клиента: «Никограм»,
  «Некограм», «Найсграм», «Nicegram», а также любое слово с окончанием
  «грам»/«gram» — так находится и незнакомый форк, даже если распознавание
  речи слегка исказило название. «Инстаграм» исключён.

## 1.3 — 12.11.2026

- Клиент Telegram больше не задан списком пакетов: приложение спрашивает
  систему, какие приложения открывают ссылки `tg://`, и берёт сторонний
  клиент — Nikogram, Nekogram, Nicegram и любой другой форк находятся сами,
  без знания их внутреннего имени.
- Сторонний клиент в приоритете перед официальным Telegram, даже если
  официальный назначен обработчиком ссылок по умолчанию.
- Строка «позвонить» в записной книжке выбирается по предпочтённому клиенту;
  если такой строки нет — берётся строка стороннего клиента, и только потом
  официального.
- Исправлена формулировка README: пример озвучки без привязки к конкретному
  клиенту.

## 1.2 — 12.11.2026

- Перед прослушиванием больше нет голосовой подсказки: вместо «Говорите имя»
  и «Кому позвонить?» звучит короткий сигнал. Всё остальное по-прежнему
  озвучивается.
- Звонки в Telegram идут через установленный клиент, а не только через
  официальный: Nicegram и другие форки распознаются, клиент выбирается по
  приложению по умолчанию для ссылок `tg://`, иначе — установленный
  сторонний клиент.
- Строка записной книжки «позвонить» ищется по любому клиенту, а не только
  по официальному MIME; выбранному клиенту действие отдаётся напрямую.
- В озвучке называется клиент, через который идёт звонок: «Звоню Роме
  в Nicegram».

## 1.1 — 12.11.2026

- Звонки в Telegram: «позвони Роме в Telegram», «позвони Маше в телеге»,
  «позвони в тг Роме». Название мессенджера вырезается из фразы, контакт
  ищется по имени среди записной книжки.
- Звонок запускается действием «позвонить», которое Telegram кладёт в
  записную книжку; запасной путь — `tg://call?phone=`.
- Звонок по номеру в Telegram: «позвони 89261234567 в телеграм».
- Если Telegram не установлен, приложение говорит об этом голосом.
- Для поиска Telegram в системе добавлены запросы в манифесте
  (`<queries>`) — требование Android 11+.

## 1.0

- Первый выпуск: голосовой набор контакта по имени, выбор из нескольких
  совпадений, звонок по номеру, озвучивание через TTS.
