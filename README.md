# Голосовой звонок

Приложение для Android 13 и выше (в том числе Android 17): открыл, сказал
«позвони Маше» или «набери Никите» — телефон сам находит контакт и звонит.
Фразу можно говорить целиком, приложение само отбрасывает «позвони», «набери»,
«к», «на».

Распознавание речи — встроенное офлайн-распознавание Android
(SpeechRecognizer в on-device режиме), интернет не нужен. Требуется скачанная
русская офлайн-модель: Настройки → Система → Языки и ввод →
Голосовой ввод Google → «Скачать языки» → Русский.

## Что умеет

- Понимает «позвони Маше», «набери Никите», «вызови маму» — падежи не мешают.
- Понимает фамилию: «позвони Гюльмагомедову» найдёт «Руслан Гюльмагомедов»,
  имя и фамилию можно говорить в любом порядке. Уменьшительные тоже
  работают: «Саше» — «Александр», «Маше» — «Мария», «Пете» — «Пётр».
- Похожие контакты не путаются: «Оле» не найдёт «Олег», «Маше» — «Миша».
- Если контактов с похожими именами несколько — читает их вслух и просит
  назвать номер: «скажите номер», можно сказать «первый» или «два».
- Звонит по номеру, если произнести цифры.
- Перед прослушиванием — короткий сигнал, без голосовой подсказки: нажали
  «Слушаю», прозвучал сигнал, можно говорить имя.
- Озвучивает всё голосом через TTS, без опоры на экран; кнопка «Слушаю» с
  понятной подписью для TalkBack, размер не меньше 80 dp.
- Сказать «отмена» или «стоп» — вызов не состоится.
- Звонит в Telegram: «позвони Роме в Telegram», «позвони Маше в телеге»,
  «позвони в тг Роме». Название мессенджера можно ставить в любое место фразы,
  а название клиента знать необязательно: «в телеграме», «в некограмме»,
  «в найсграм» — всё подходит.
- Звонит в WhatsApp: «позвони Роме в ватсап», «в вотсапе», «в вацап»,
  «в WhatsApp», «через ватсап», даже если распознавание разбило слово:
  «в вот сап». Подходит и WhatsApp Business.
- Звонит во ВКонтакте: «позвони Роме в вк», «во вконтакте», «в контакте».
- Понимает MAX: «позвони Роме в макс», «в Максе», «через Макс». Без предлога
  «Макс» — это имя: «позвони Максу» находит контакта Максима.

## Звонки в Telegram

Нужен Telegram для Android с включённой синхронизацией контактов (по
умолчанию так и есть). Приложение берёт из записной книжки действие
«позвонить в Telegram», которое Telegram добавляет каждому контакту, и
запускает его — звонок начинается сразу, экран Telegram открывается уже с
гудками.

Если синхронизация выключена, приложение пробует запасной путь
`tg://call?phone=<номер>`: он сработает, если номер есть в контактах
Telegram. Кому позвонить по номеру — «позвони 89261234567 в телеграм».

Клиент выбирается сам. Приложение спрашивает систему, что откроется по
ссылке `tg://`, — это и есть клиент, выбранный в настройках телефона «по
умолчанию для ссылок», — и звонит через него, даже если это официальный
Telegram.
Если приложение для ссылок не назначено, а клиентов установлено несколько,
приложение спрашивает голосом: «Установлено несколько клиентов Telegram:
1. Nikogram, 2. Telegram. Скажите номер клиента». Выбор запоминается;
сбросить его можно долгим нажатием на «Слушаю». Назначенное в системе
приложение важнее запомненного выбора.

Название клиента знать не нужно: подойдёт любой форк, который ставится
обработчиком `tg://`. Список пакетов тоже не нужен — незнакомый форк
находится через систему. Строка «позвонить» в записной книжке ищется по
любому клиенту. В озвучке слышно название клиента, через который идёт
звонок: «Звоню Роме в Nikogram».

Видеозвонки не поддерживаются — всегда голосовой.

## Звонки в WhatsApp

Нужна включённая синхронизация контактов в WhatsApp. Приложение берёт из
записной книжки строку «позвонить в WhatsApp», которую WhatsApp добавляет
каждому синхронизированному контакту, и запускает её — звонок начинается
сразу. Работают оба приложения: обычный WhatsApp и WhatsApp Business.

Клиента выбирать не нужно: WhatsApp один. Если контакта в WhatsApp нет,
приложение так и говорит — «Проверьте, что контакт есть в WhatsApp».

По номеру позвонить нельзя: WhatsApp не даёт ссылку вида «позвони по
номеру». На фразу «позвони 89261234567 в ватсап» приложение отвечает, что
по номеру в WhatsApp позвонить нельзя, и просит назвать имя контакта.

## Звонки во ВКонтакте

ВК не добавляет контактам строку «позвонить», поэтому звонок идёт по
ссылке `https://vk.com/call?id=<числовой id>`. Числовой id приложение
берёт из контактов, которые ВКонтакте синхронизировал с записной книжкой
(там сохраняется ссылка на страницу). Нужно, чтобы в ВК была включена
синхронизация контактов.

Если ВК не синхронизирован или у контакта нет id, приложение честно
говорит: «Проверьте, что контакт синхронизирован с ВКонтакте». По номеру
во ВКонтакте позвонить нельзя — там тоже нужен именно контакт.

Видеозвонков нет ни в WhatsApp, ни во ВКонтакте: приложение ищет только
строку голосового звонка.

## Звонки в MAX

MAX (пакет `ru.oneme.app`) не даёт другим приложениям начинать звонок: у
него нет ни строки «позвонить» в записной книжке, ни ссылки вида
«позвони контакту». Поэтому приложение не делает вид, что звонок начался, а
честно говорит: «MAX не даёт начать звонок из другого приложения. Открываю
MAX — найдите контакт и нажмите трубку в чате», — и открывает MAX. Обычной
связью вместо MAX оно при этом не звонит.

По номеру в MAX позвонить из другого приложения тоже нельзя — приложение
говорит об этом и просит назвать имя контакта.

Если в будущих версиях MAX начнёт добавлять контактам строку «позвонить»,
звонок заработает сразу, как в Telegram и WhatsApp: приложение уже умеет
запускать такую строку.

## Установка и обновление

Идентификатор приложения постоянный — `ru.gyulmagomedov.voicedial`, — и все
сборки подписываются одним и тем же ключом `keystore/voicedial.jks`. Поэтому
новая версия ставится поверх старой как обновление, настройки и запомненный
клиент сохраняются. Менять идентификатор и ключ нельзя: с другим ключом
Android откажется обновлять приложение, с другим идентификатором получится
второе приложение рядом.

Один раз при переходе с версии 1.4 и раньше: у тех сборок был другой
идентификатор (`ru.aleshka.voicedial`) и другая подпись, поэтому старую версию
нужно удалить вручную. Дальше обновления проходят поверх.

## Сборка

Локально нужен JDK 17 и Android SDK. Без них проще через GitHub Actions:
workflow `.github/workflows/build.yml` собирает `app-debug.apk` и выкладывает
артефактом voicedial-apk.

## Разрешения

Микрофон, контакты, звонки. Ничего не отправляется в сеть.
